# CodeAlpha Calculator

A responsive and user-friendly calculator built using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship.

## Features

- Basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Percentage calculation
- Decimal number support
- Clear and delete functions
- Keyboard support
- Responsive design
- Mobile-friendly interface
- Dark glassmorphism UI
- Error handling for invalid calculations and division by zero

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Use the calculator in your browser.
